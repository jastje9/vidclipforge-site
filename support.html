Help & support

VidClipforge desktop software · Product information and contact

VidClipforge helps creators prepare vertical highlights from gaming recordings. Most rendering happens locally and optional platform uploads require separate authorization.

Getting started

  1. Open VidClipforge on your desktop.
  2. Select a local file or a source you have permission to use.
  3. Choose your analysis mode and rendering style.
  4. Review clip candidates and exported MP4 drafts.
  5. If your installed version supports it, connect a platform through its official sign-in flow before uploading.

Account connections

Connecting an account does not grant permission to reuse third-party content. Publishing availability depends on platform API approval, granted scopes and account status. For assistance, refer to the application's own logs and documentation.

How to reach the project owner

Use the VidClipforge site repository issue tracker for project questions once it is enabled. Please do not post passwords, API secrets, personal access tokens, OAuth JSON files or private videos in an issue.

Privacy requests

For questions about local files, account authorization or data removal, open a support issue with no sensitive credentials, or revoke the integration using your connected platform's account security settings.

This website documents the desktop application. It does not itself host the clip-processing pipeline, authenticate TikTok users or upload videos.
